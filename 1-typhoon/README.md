# 1. 태풍 영향 정량화

태풍 트랙에서 **항만이 강풍에 얼마나 오래 노출됐는지**를 계산합니다.
이 값이 2단계 robust 스케줄링의 시나리오 입력이 됩니다.

---

## 결론부터 — 세기보다 지속시간

항만이 멈추는 걸 결정하는 건 **태풍이 얼마나 센가가 아니라 얼마나 오래 머물렀나**입니다.

부산 기록을 보면 바로 보입니다.

| 태풍 | 태풍 크기(IKE) | 34kt 노출 | 최저 기항 |
|---|---|---|---|
| 타파 2019 | 399 | 24h | 0척 |
| 하이선 2020 | 242 | 12h | 0척 |
| 미탁 2019 | 209 | 6h | 1척 |
| 힌남노 2022 | 190 | 12h | 0척 |
| 마이삭 2020 | 155 | 6h | 0척 |

**크기가 399든 155든 전부 0척**입니다. IKE 순서대로 줄을 세워도 결과는 다 똑같아요.
바람이 34kt를 넘으면 크레인은 그냥 멈추고, 그 위로 더 세다고 더 멈추지는 않습니다.
미탁(209)은 노출이 6시간뿐이었는데도 1척까지 떨어졌습니다.

차이는 **다음 날**에 납니다. 164개 사례로 보면:

| 34kt 노출 | 상륙일 | 이튿날 |
|---|---|---|
| 6–12h | −75.8% | +0.6% |
| 12–24h | −85.3% | −27.4% |
| 24–72h | −89.7% | **−74.5%** |

잠깐 스친 태풍은 **다음 날 바로 정상**입니다. 오래 머문 태풍은 이튿날까지 끌려갑니다.
같은 걸 태풍 크기로 나누면 −21 / −52 / −49로 뒤죽박죽입니다.

> **그래서 주 지표는 `hours_r34`(34kt 노출시간)입니다.**
> IKE도 같이 계산하지만 보조 자료로만 둡니다. 이유는 바로 아래.

---

## 노출시간은 어떻게 구했나

주 지표 `hours_r34`를 만드는 과정입니다. **이게 이 폴더의 핵심 산출물**입니다.

### 쓴 데이터 — IBTrACS v04r01

미국 NOAA가 전 세계 기상기관의 태풍 관측을 하나로 합쳐 공개하는 **베스트트랙**입니다.
우리는 서태평양(WP) 파일만 씁니다. 무료, 가입 불필요.

```
파일   ibtracs.WP.list.v04r01.csv   약 110MB (git에 없음, download_ibtracs.sh로 받음)
단위   태풍 1개 × 관측시점 1개 = 1행
규모   2018년 이후 태풍 276개, 트랙 시점 9,036개
간격   6시간 (00/06/12/18 UTC)
```

쓰는 컬럼은 15개뿐입니다.

| 컬럼 | 내용 |
|---|---|
| `SID` `SEASON` `NAME` | 태풍 식별 |
| `ISO_TIME` | 관측 시각 |
| `LAT` `LON` | 태풍 중심 위치 |
| `USA_WIND` | 최대풍속 |
| `USA_R34_NE/SE/SW/NW` | **34kt 바람이 닿는 반경** (4방향, 해리) |
| `USA_R50_*` `USA_R64_*` | 50kt·64kt 반경 |

`USA_R34_NE = 120`이면 "태풍 중심에서 북동쪽으로 120해리(222km)까지 34kt 바람이 분다"는 뜻입니다.
**태풍은 한쪽으로 치우쳐 있어서 방향마다 반경이 다릅니다.** 그래서 4개로 나눠 줍니다.

> 읽을 때 주의: 첫 줄 다음에 단위 행이 하나 더 있습니다 (`skiprows=[1]`).
> 그리고 3시간 보간행이 섞여 있어 00/06/12/18시만 남깁니다.

### 계산 절차

**① 태풍 중심에서 항만까지 거리와 방향을 구합니다.**

```python
dist, brg = haversine_bearing(태풍_위도, 태풍_경도, 항만_위도, 항만_경도)
```

지구가 둥그니까 하버사인 공식을 씁니다. 방위각 `brg`는 북쪽 0도 기준입니다.

**② 그 방향이 어느 분면인지 정합니다.**

```
brg < 90  → NE      90~180 → SE
180~270   → SW      그 외   → NW
```

**③ 그 분면의 반경과 비교해 안에 있는지 봅니다.**

```python
if 거리 <= USA_R64_그분면:   64kt 권역
elif 거리 <= USA_R50_그분면: 50kt 권역
elif 거리 <= USA_R34_그분면: 34kt 권역
else:                        영향권 밖
```

예를 들어 태풍이 부산 남서쪽에 있으면 부산은 태풍의 **북동(NE)** 쪽에 있는 셈이니,
`USA_R34_NE`와 거리를 비교합니다.

**④ 안에 있던 시점마다 시간을 더합니다.**

관측이 6시간 간격이므로, 한 시점은 앞뒤 간격의 절반씩 **총 6시간**을 대표합니다.

```
00시  영향권 밖
06시  34kt 안  → +6h
12시  34kt 안  → +6h    누적 12h
18시  영향권 밖
```

이렇게 누적한 게 `hours_r34`입니다. "그 항만에서 크레인이 멈춰 있었을 시간"의 대리값이죠.

### 산출물 두 가지

```
port_exposure.csv     태풍 1개 × 항만 1개 = 1행   (태풍 단위 집계)
exposure_daily.csv    항만 1개 × 날짜 1일 = 1행   (421행)  ← 패널 분석 입력
```

둘을 나눈 이유는 **회귀에 쓰려면 날짜 단위여야 하기 때문**입니다.
태풍 단위로는 "며칠에 무슨 일이 있었나"를 항만 기항 데이터와 붙일 수 없습니다.

같은 날 태풍 둘이 겹치면 시간은 더하고 강도는 최댓값을 씁니다.

### 알아둘 점

**반경 자료가 42%만 채워져 있습니다.** 겁먹을 숫자가 아닙니다 —
빈 경우 대부분은 태풍이 아직 34kt에 못 미쳤거나 온대저기압으로 바뀐 단계라
**실제로 반경이 0인 게 맞습니다.** 부산 27개 사건 전부 최근접 시각 ±12h에 자료가 있습니다.

**미국(USA) 컬럼만 씁니다.** 일본(TOKYO)·한국(KMA) 컬럼도 있지만
장축/단축 타원 형식이라 4분면 방식에 바로 안 맞고, KMA는 2015년부터만 있습니다.

## IKE는 왜 안 맞았나

IKE(통합운동에너지)는 **태풍 전체가 가진 에너지**입니다. 태풍이 얼마나 큰 놈인지를 재죠.

그런데 그건 *태풍의 크기*지 *우리 항만이 받은 충격*이 아닙니다.
거대한 태풍이 500km 밖을 지나가면 IKE는 크지만 부산은 멀쩡합니다.

IKE의 결함이 아니라 **쓰임새가 다른 것**입니다. 원래 항만 단위 지표로 만들어진 게 아닙니다.
시도했고, 데이터로 기각했고, 노출시간으로 바꿨다 — 이 과정 자체가 결과입니다.

아래는 그래도 IKE를 어떻게 계산했는지입니다. 보조 자료로 쓰거나 지표를 고칠 때 참고하세요.

## IKE가 뭔가

최대풍속만으로는 태풍의 파괴력을 설명할 수 없습니다. 같은 등급이라도 바람이 넓게 퍼지면
피해가 훨씬 큽니다. Powell & Reinhold(2007)는 **풍속장 전체를 적분한 운동에너지**를 제안했습니다.

```
IKE = ∫ ½ ρ U² dV
```

ρ는 공기밀도, U는 풍속, V는 영향 영역입니다.

### 구현 방법

격자 바람장이 없으므로, IBTrACS가 주는 **4분면별 풍속반경**으로 동심 고리를 만들어 근사합니다.

```
       NW │ NE          각 분면마다 34 / 50 / 64 kt 반경이 주어짐
      ────┼────         → 고리 3개 (34–50, 50–64, 64–Vmax)
       SW │ SE          → 고리마다 대표풍속 × 면적 × 두께로 에너지 합산
```

고리 하나의 기여:

```python
area = (π/4) × (r_out² − r_in²)        # 4분면이므로 π/4
U    = √((lo² + hi²)/2)                # 에너지 평균이라 제곱평균
IKE += ½ × ρ × U² × area × 1m          # 표층 1m 두께 가정
```

4분면 × 3고리 = 12개를 합쳐 시점별 IKE(TJ)를 얻고, 태풍 전체는 그 최댓값을 씁니다.

```
scripts/

output/
  storms.csv                   태풍별 IKE·최대풍속·부산 최근접거리
  port_exposure.csv            태풍 × 한국 항만 노출시간

       1-typhoon/data/ibtracs.WP.list.v04r01.csv \

```

## 주요 결과

2000년 이후 **부산이 34kt 바람권에 든 태풍 27개**. 상위권이 실제 피해 사례와 일치합니다.
아래 표의 IKE는 참고용이고, 실제로 쓰는 건 노출시간 열입니다.

| 태풍 | 연도 | 노출 34kt | IKE(TJ) | 최근접 |
|---|---|---|---|---|
| TAPAH 타파 | 2019 | 24h | 399 | 140km |
| NANMADOL 난마돌 | 2022 | 18h | 235 | 210km |
| HINNAMNOR 힌남노 | 2022 | 12h | 190 | 132km |
| MAEMI 매미 | 2003 | 12h | 72 | 71km |

아시아로 넓히면 **가오슝(대만)이 압도적**입니다 — 4년간 14회, 390시간.
부산은 20년에 27회이니 밀도가 7배쯤 됩니다.

## 처치 정의를 넓힐 여지

**34kt 기준은 다소 엄격합니다.** 2021년 오마이스·찬투는 이 기준을 통과하지 못했지만
실제로 부산항을 멈췄습니다 ([findings](../docs/findings.md) 참조).
기준을 30kt로 낮추거나, 인접일을 포함하는 식으로 넓힐 수 있습니다.
