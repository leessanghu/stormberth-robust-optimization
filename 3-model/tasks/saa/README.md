# saa — 표본평균근사 (RP)

> 공통 안내 → [`../../START.md`](../../START.md)

## 내가 할 일

**불확실성의 분포를 안다고 보고**, 거기서 시나리오 K개를 뽑아 **평균**을 최소화합니다.

## 이게 왜 중요한가

로버스트와 **정면으로 대비되는** 방법입니다. 둘 다 불확실성을 다루지만 가정이 다릅니다.

| | 가정 | 최소화 대상 |
|---|---|---|
| 로버스트 | "최악이 이 범위" (집합) | **최댓값** |
| SAA | "분포가 이럴 것" (확률) | **평균** |

같은 불확실성을 **어떻게 모형화하느냐**가 결과를 가른다는 걸 보여주는 자리입니다.
이 둘을 나란히 놓지 않으면 "로버스트가 좋다/나쁘다"를 말할 근거가 없습니다.

> 확률계획 용어로 이 값을 **RP** (recourse problem) 라고 합니다.


## K 를 몇으로 할 것인가 

`config.yaml` 의 `n_scenario_saa` 입니다. K 를 키우면 참 평균에 가까워지지만 느려집니다.
**K 를 바꿔가며 성능과 시간을 재서 수렴 곡선을 그리는 게 내 보고서 절의 핵심입니다.**
K = 5 / 10 / 20 / 40 정도면 충분합니다.

## 확인

```bash
python 3-model/run_all.py --only saa
python 3-model/run_all.py              # 정리 점검까지 보려면 전부 돌려야 합니다
```
