# 23개 항만 패널 분석 (2026-11-19 추가)

부산 1개 항만(n=1)의 전후 비교에서 **19개 항만 × 2,874일 이중차분**으로 넓혔습니다.

## 왜 넓혔나

부산만 보면 *"9월이라 원래 적은 것 아니냐"*, *"그 주에 세계 물동량이 줄었던 것 아니냐"* 에
답할 수 없습니다. 같은 날 태풍을 안 맞은 항만이 평소대로였다면 그 차이가 태풍 효과입니다.

## 설계

```
log(1+컨테이너기항)_it = Σ_k β_k·1[상대일=k] + 항만FE_i + 날짜FE_t + ε_it
```

- **날짜FE**가 "그날 세계 해운이 조용했다"를 흡수 (휴일·요일·경기 포함)
- **항만FE**가 "홍콩이 부산보다 원래 크다"를 흡수
- 기준 상대일 D−7, 표준오차는 항만 클러스터

**표본**: 컨테이너 기항 중앙값 5척 이상인 19개 항만.
가고시마·기타큐슈(0척)·나하(1척)·울산(3척)은 제외했습니다.
이 4개가 전체 노출일 328건 중 **85건(26%)** 을 갖고 있어 신호를 크게 희석시키고 있었습니다.
→ 분석 표본 54,606행, 노출일 243건, 에피소드 166개.

## 누적 — 사라진 기항은 메워지지 않는다

평년 대비 척·일 기준 누적입니다.

```
D−1  누적 −14.4척
D 0  누적 −27.4척
D+1  누적 −34.3척   ← 최저점
D+3  누적 −30.5척
D+7  누적 −27.0척
D+14 누적 −30.6척
```

D+3~D+4의 반등이 손실의 **약 20%만** 회복시킵니다. 나머지는 2주 안에 돌아오지 않습니다.
(단 D+5 이후 계수는 전부 비유의라 누적 수준의 불확실성은 큽니다.)

**해석**: 밀린 배가 전부 나중에 오는 게 아니라, **상당 부분은 아예 다른 항만으로 가거나
항차 자체가 사라집니다**. 항만 입장에서는 회복 가능한 물량과 영구 손실이 섞여 있고,
이것이 빠른 복구 스케줄링의 경제적 동기를 직접 뒷받침합니다.
