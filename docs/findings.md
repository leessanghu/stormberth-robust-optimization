## 1. 태풍이 부산항을 실제로 멈춘다

2019~2026년 PortWatch 일별 기항(평년 일평균 33척) 기준입니다.

```
기항 0척인 날 (2,874일 중 5일)
  2019-09-22  타파
  2020-09-02  마이삭
  2020-09-06  하이선 전날
  2022-09-05  힌남노
  2023-08-09  카눈 전날

기항 5척 이하인 날 8일도 전부 태풍일
```

결측이 0인 데이터에서 0척이 나왔으므로 **"자료 없음"이 아니라 실제 정지**입니다.
베이스라인 가정이 전혀 필요 없는, 가장 강한 증거입니다.

덤: 2021-08-23(오마이스), 2021-09-16(찬투)도 항만을 멈췄는데
IKE 34kt 기준으로는 처치로 잡히지 않았습니다. **처치 정의를 넓힐 여지**가 있습니다.

## 울산에서 배운 것 (참고)

처음에는 울산 선석배정 데이터로 검증을 시도했습니다. 결과:

- 태풍 직전 접안 중단은 재현됨 (평년의 8~30%)
